About Me

Creator of this Cancer Awareness Website

Hi! My name is Saanvi and I am a high school student who created this Cancer Awareness website as a science project. I have always been interested in biology and learning about how diseases affect the human body. That interest inspired me to create this website and learn more about cancer.

This project was made to spread awareness about cancer and explain important topics in a simple and easy way for students and readers. While making this website, I researched different cancer types, causes, symptoms, treatments, and prevention methods.

Why I Created This Website

Many people hear about cancer often, but not everyone understands how it develops or how serious it can become. I wanted to make a website that presents information clearly without using too many difficult medical terms.

I also wanted this project to look creative and interesting instead of only feeling like textbook notes.

One important thing I learned while creating this project is that awareness and early diagnosis can help save lives.

What I Learned

While creating this website, I learned many new things about cancer biology, cancer incidence statistics, risk factors, and prevention methods. I also improved my HTML and CSS web designing skills during this project.

My Goal

My goal is to help people understand cancer better and spread awareness about the importance of healthy habits, regular checkups, and early detection. I hope this website helps students and readers learn more about cancer in a simple and interesting way.

Thank you for visiting my website and taking the time to learn more about cancer awareness.
